# Telco Customer Churn: Exploratory Data Analysis and Dashboard
#### By Arturo Rosales V.

A Exploratory Data Analysis (EDA) project about Telecommunications company called Telco, and they Customers Churn. 

In this EDA project, was handled customer use data and, from that data, build key insights to Telco company decisions.

The dashboard app shows key insights and many important metric to Telco manager. The objective is advice to Telco company that they are losing important customers and with that, they are losing income.
